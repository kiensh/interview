## Quick Navigation

### Go Core Concepts
- **Basics**: Variables, Constants, Data types, Control flow, Functions, Pointers
- **Concurrency**: Goroutines, Channels, Select, Mutex, WaitGroup, Race conditions
- **Types**: Structs, Interfaces, Embedding, Type assertions, Type switches
- **Errors**: Error interface, Custom errors, Wrapping, Sentinel errors

### Go Advanced
- **Modules**: go.mod, Versioning, Private modules
- **Reflection**: reflect package, Type introspection
- **Generics**: Type parameters, Constraints, Type inference
- **Context**: Cancellation, Timeouts, Values

### API & Web Development
- **REST**: HTTP handlers, Routing, Middleware patterns
- **gRPC**: Protocol Buffers, Streaming, Interceptors
- **Real-time**: WebSockets, Server-Sent Events

### Data & Messaging
- **Databases**: Connection pooling, Transactions, ORMs (GORM, sqlx, sqlc)
- **Message Queues**: Kafka, RabbitMQ, Event sourcing
- **Caching**: Redis integration, Cache strategies

### Gin Framework
- **Core**: Routing, Groups, Middleware, Binding, Validation
- **Advanced**: Context, Graceful shutdown, Recovery
- **Features**: Auth (JWT), Sessions, File handling, Templates

### Performance & Observability
- **Profiling**: pprof, CPU/Memory profiling, Benchmarks
- **Patterns**: Worker pools, Fan-out/Fan-in, Circuit breaker
- **Observability**: zerolog/zap, Prometheus, OpenTelemetry
